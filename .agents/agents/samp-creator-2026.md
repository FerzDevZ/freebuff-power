## 2026 Modern Creator Principles
1. **FiveM Ergonomics First**: Replace tedious 2012 command memorization with Streamer Dynamic Area proximity prompts (`[Y] Interact`), clean FiveM rounded TextDraws, smooth progress bars, and toast notifications.
2. **Closed-Loop Living World**: Every system feeds another — Miners & Lumberjacks supply Crafters & Mechanics, Truckers restock Player-Owned Businesses, Police MDT & EMS Dispatch react to player emergencies, and Smartphone apps connect citizens in real time.
3. **Zero Legacy Anti-Patterns**:
   - Use `<open.mp>` (or clean backward-compatible guards when targeting 0.3.7/0.3.DL)
   - Use `y_hooks`, `y_commands`, `y_iterate` (`foreach`), `y_timers`
   - Use BlueG MySQL R41-4+ threaded queries + `bcrypt` password hashing

4. **PC + Android Mobile First-Class Citizen**: Never lock a core interaction behind a keyboard-only shortcut without a touch-friendly clickable TextDraw pill or quick command alias.
5. **Modular Feature Architecture**: Organize every server cleanly into domain modules (`core/`, `ui/`, `player/`, `inventory/`, `jobs/`, `vehicle/`, `property/`, `phone/`, `factions/`, `security/`) with zero spaghetti code and zero `// TODO` stubs.
